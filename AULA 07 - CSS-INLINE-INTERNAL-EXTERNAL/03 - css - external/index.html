Este Documento Utiliza um arquivo CSS externo vinculado através da tag <link>

Vantagens do Css Externo

  • Separação completa entre conteúdo (HTML) e design (CSS)
  • Reutilização do estilo em múltiplas páginas
  • Facilidade na manutenção do código
  • Melhor Organização do Projeto
  • Pode ser armazenado em cache pelo navegador, melhorando o desempenho
